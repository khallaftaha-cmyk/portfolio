I am writing to express my strong enthusiasm for applying to the Full Stack Engineering pathway of the HENNGE Global Internship Program (GIP). My most defining engineering project is my Cloud Notes API — a production backend built with FastAPI, PostgreSQL, and Docker, deployed live on AWS EC2 via Terraform IaC and GitHub Actions CI/CD. That moment transformed full-stack engineering from a label into an intuitive craft. It was a simple realization, but it permanently altered how I evaluate developer productivity.

My enrollment in The University of Tokyo's Global Consumer Intelligence (UTokyo GCI) program reflects my active commitment to engaging with Japanese data science and engineering methodologies.
